为什么值得用

和「只会记」的记忆工具不同：ProactiveAgent 会记，也会在想该提醒你的时刻主动开口。

🧠

记忆是「用户级资产」

不是工具级资产。你在 Claude Code 里教的偏好和流程，Kimi Code、Cline、Cursor 也能直接召回——跨工具共享同一份长期记忆。

cross-tool memory
💡

主动建议：该沉默时沉默

不只是被动检索。在合适的时机主动给出纠正 / 跟进 / 自动化 / 待办 / 技能五类建议，且遵循「该沉默时沉默」的克制原则。

proactive suggestions
🛡️

防投毒设计

自动提取的记忆默认 pending，需确认后才进入召回。恶意或错误内容不会污染记忆库，安全有底线。

anti-poisoning
🔌

即插即用

一个 MCP 挂所有。无需 clone 仓库、无需 bun、无 Node 依赖烦恼——npm 安装即用，零配置起步。

zero-dependency
📁

按项目隔离

记忆分项目层与全局层：项目专属规则不串味，全局偏好处处可用。支持逃生模式，隐私可控。

scoped memory
⏱️

时间感知

定期需求、周期任务、每日复盘——时间感知的建议引擎会在对的时间提醒你，还有 TTL 归档治理记忆规模。

time-aware

快速开始（< 1 分钟）

无需 clone 仓库，无需 bun，一条命令开始。

1 安装

npm install @proactive-agent/mcp

零依赖 npm 包，安装即可用。

2 初始化挂载

npx proactive-mcp init

自动生成 Claude Code / Cline / Cursor 挂载配置 + hooks。支持 --kimi、--local、--force 选项。

3 手动挂载（任意宿主）

"command": "npx",
"args": ["-y", "@proactive-agent/mcp@latest"]

任何支持 MCP 的客户端，添加 stdio server 即可。

兼容所有 MCP 宿主

数据默认存在 ~/.proma-proactive/（用户级共享，跨工具复用），可用 PROACTIVE_DATA_DIR 覆盖。
