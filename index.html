快速开始

一条命令，1 分钟搞定。

1安装

npm install @proactive-agent/mcp

零依赖，装完即用。

2初始化

npx proactive-mcp init

自动挂载到 Claude Code、Cline、Cursor，支持 --kimi。

3手动挂载

"command": "npx",
"args": ["-y", "@proactive-agent/mcp@latest"]

任何支持 MCP 的客户端，添加 stdio server 即可。

✓ Windows 与 Linux/macOS 安装命令完全一致（仅需 Node ≥ 18）。
只用 npm / npx / node，三平台零差异，无需 curl。
数据目录默认 ~/.proma-proactive/（Windows 为 C:\Users\<用户名>\.proma-proactive\）。

兼容所有 MCP 宿主

数据存在 ~/.proma-proactive/，跨工具共享。
